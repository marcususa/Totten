The goal is to build a catalog instead of a library for chess games. You can import .pgn files, and the program will catalog games by frequency based on the ECO, opening, and variation. The Mixed Collections feature allows you to create "playlists" of games you can analyze. Engine selection will be added later, but Stockfish is currently the only one supported right now.

Future development will include pattern analysis and the exploration of relationships between chess patterns and music theory.
